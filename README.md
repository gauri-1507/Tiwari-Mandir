# Teen Kalash Tiwari Mandir website

A self-contained three-page static website. Open `index.html` in any modern browser, or deploy the complete folder to any static hosting provider.

## Before publishing

Add the temple’s confirmed receipt/WhatsApp contact number in `seva.html` (search for `Contact number`). No number was supplied, so none has been invented.

## Included pages

- `index.html` — Welcome and About
- `darshan.html` — News and Gallery
- `seva.html` — Support a cause, QR payment and Contact
